# План приёмки

Для каждого пункта отметьте фактический результат после запуска на своей машине.

| Проверка | Ожидаемый результат |
|---|---|
| Гость открывает /dashboard, /suppliers/create | Переход на /login |
| Регистрация с корректными данными | Аккаунт создан, переход к входу |
| Email повторяется | Ошибка, второй аккаунт не создан |
| Пустое имя, некорректный email, пароль меньше 6 символов | Отказ; также проверить POST без JS |
| Верный / неверный пароль | Вход / сообщение об ошибке |
| Кабинет | Имя, email и число собственных поставщиков |
| Создание с одним названием | Запись создана, контакты отображаются тире |
| Пустое название или телефон из букв | Ошибка, данные формы сохранены |
| Редактирование | Изменения сохраняются после обновления страницы |
| Отмена подтверждения удаления | Запись остаётся |
| Подтверждение удаления | Запись исчезает, повторный доступ — 404 |
| Второй аккаунт | Не видит поставщиков первого |
| Второй аккаунт обращается к чужому edit/delete | 404, чужие данные не изменены |
| POST без CSRF или с неверным токеном | 403, данные не изменены |
| GET на удаление собственной записи | 405, запись остаётся |
| HTML-теги в названии | Отображаются текстом, код не выполняется |
| Поиск с кавычками/SQL-подобной строкой | Нет ошибки SQL и чужих данных |
| Выход и повторное открытие /dashboard | Переход на /login |
| Окно 1366×768 и 390×844 | Формы доступны; таблица прокручивается на узком экране |
| Поиск при отключённом JavaScript | Работает обычным GET-запросом |
